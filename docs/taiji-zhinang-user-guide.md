# 太极智囊使用说明

太极智囊把固定版本的专业角色接入现有聊天、附件和成果工作区。选择角色会创建一个新任务；它不会自动发送消息，也不会替换当前模型、工作区或档案。

## 找到合适的角色

1. 从左侧或顶部导航进入“智囊库”。
2. 在“精选角色”查看固定精选，或切到“全部角色”浏览完整目录。
3. 使用搜索框查找中文名、英文名、能力或标签；领域筛选可以和搜索、收藏、最近一起使用。
4. 每页最多显示 24 个角色。没有结果时，可直接清除筛选或浏览全部角色。

角色卡片上的“查看详情”会打开完整说明。详情包括角色定位、能力、限制、改编说明、示例任务、交付示例、来源版本和 MIT 许可。标为“示例，非已生成文件”的内容只说明可能的交付形式，不代表文件已经生成。

## 收藏与最近使用

点击卡片或详情中的收藏按钮可以收藏或取消收藏。收藏按当前配置档案保存，不跨档案共享。

“最近使用”只显示已经实际受理过消息的智囊任务。卡片上的“继续最近任务”进入该角色最近一个仍可访问的真实任务。删除一个任务后，系统会回退到同角色其他可访问任务；复制或分支任务保持独立，不会被错误折叠。

如果某个已收藏角色在新版目录中下架，它仍会以“当前版本不可用”显示安全摘要和已经验证的历史任务入口。此时不能用它创建新任务，但可以取消收藏。

## 创建角色任务

- 点击“使用此智囊”会创建一个空白新任务。先补充具体需求，再发送消息。
- 点击某条示例旁的“使用此示例”会创建新任务并预填这一条示例。预填不会自动调用模型；确认或修改后再发送。
- 已经使用过的角色会同时提供“继续最近任务”和“使用此智囊”，可自行选择继续历史或另开任务。

创建前，系统会保存当前任务草稿。保存或创建失败时，当前任务、草稿和尚未上传的附件会留在原处，可按提示重试。连续点击创建只会受理一个逻辑请求；如果服务已经受理但响应丢失，再次点击会沿用同一个请求标识恢复原任务。

## 固定角色与历史说明

角色任务顶部会显示角色标签。点击标签可以查看创建时保存的历史角色说明；即使目录以后更新，旧任务仍按创建时的角色快照继续工作。

角色在整个任务内固定，因此该任务中 `/personality` 不可用。普通聊天仍可使用原有 personality 和模型配置。若需要另一种角色或普通聊天，请新建相应任务。

## 附件、成果与恢复

智囊任务沿用现有附件和成果流程。发送前选择的附件只属于当前任务；切换到新任务后不会自动带入。

当角色实际调用文件工具并成功写入当前工作区后，“成果”面板会出现文件，可预览或下载。只有工具确认成功且文件位于当前工作区时才显示成果；失败、取消、越界路径或仅有同名旧文件都不会被标成新成果。

目录或详情加载失败时，使用页面上的“重试”。收藏保存失败后按钮恢复为原状态，可直接再试。模型调用失败或取消后，任务保留已经提交的用户消息；确认状态恢复后可以继续发送。

## 来源和使用边界

内置目录由固定上游版本和一个太极本地角色组成。来源链接只允许 `http` 或 `https`；其他协议只显示文本。完整上游原文、中文展示和太极运行适配分开保存，详情中的改编说明会说明本地边界。

角色说明提供方法和工作方式，不会自行增加工具、权限、联网能力或多 Agent 授权。需要外部访问、执行工具、专家团、委派或其他高影响操作时，仍以当前产品能力、用户授权和运行策略为准。
