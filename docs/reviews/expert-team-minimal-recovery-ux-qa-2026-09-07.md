# 前端 UX QA 报告：专家团最小恢复

## 状态与范围

带限制完成。本报告覆盖本次专家团最小恢复的源码 UI、真实 Electron 操作和证据边界。交付语义阻断的受限退回已在真实 Electron 中走通；研究报告已完成内容复核、语义 gate、DOCX 自检、本机 WPS 人工检查与确认闭环。

本次只覆盖 standalone 专家团。退回入口只在服务端给出完整、哈希绑定的恢复动作时出现；不增加普通重试，也不绕过语义 gate、冻结阶段身份或模型阶段自动批准策略。

## 受影响用户路径

1. 已生成内容在交付语义检查中被阻断，工作台显示受限恢复说明、诊断和“退回复核阶段修改”。
2. 空反馈点击提交时，显示“请先填写需要修改的内容”，焦点回到带标签的修改意见 textarea，且不触发生成。
3. 填写具体反馈后，提交只携带服务端绑定的阶段、产物和版本身份；失败交付预留失效，任务回到唯一 review 阶段重新生成。
4. 研究 V2 卡片保留资料摘要；普通内容任务使用同一受限恢复合同。两者都将恢复入口放在已保留长正文之前。

## 未核验模型知识语义修复

- 根因：研究 V2 提示词只要求使用“模型知识·未核验”和 `claim_usage` 唯一性，没有明示交付 gate 所要求的逐条原声明、所在章节和标签数量合同。实际被阻断的版本将七条声明改写，且一个分析章节为四条声明放置二十个保守标签，因此触发七个原声明章节失配和一个标签计数失配。
- 最小修复：仅在研究草稿和研究复核提示词中补足逐条原声明、声明章节和至少一处就地标签的规则；允许额外保守标签。gate 仍严格检查原声明、模型知识章节隔离、无来源/脚注和最少标签数，不采用同义改写匹配或关闭 gate。
- 背景口径：当声明复述 Brief 已提供但缺少外部来源的背景时，正文说明“用户提供的背景，原文待核验”；“模型知识·未核验”只描述核验状态，不表示背景由模型生成。冻结证据和既有运行记录未被手改。
