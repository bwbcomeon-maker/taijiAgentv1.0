# Windows 安全设置保存与重启生效修复

## 影响

Windows 桌面候选的安全设置保存不再调用仅支持 POSIX 的凭据事务写入器。基础策略和两项扩展能力保存到用户本地 runtime-home 内的独立、固定 schema 文件；启动器在创建 Agent/WebUI 子进程前加载该文件，因此选择可在完全退出并重开后生效。

该文件不包含 API Key 或其它凭据。无效、超限、链接或包含未知字段的文件按企业安全且扩展关闭处理。macOS/Linux 的 canonical `.env` 行为不变。

## 验证边界

源码单元测试、完整本地门禁和隔离浏览器交互已通过。尚未生成新的 Windows 安装包，也未在用户 Windows 安装态执行“保存、完全退出、双击重开”的闭环验收。

WebUI `CHANGELOG.md` 已超过本地安全门禁的非源码文件 1 MiB 上限，因此本次不修改该历史文件、不放宽门禁，以本记录和安全能力手册承载变更说明。
